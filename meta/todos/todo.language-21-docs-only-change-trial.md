## Goal

Measure fresh-agent implementation and maintenance.

## Acceptance criteria

- Freeze task specifications, acceptance cases, docs versions and budgets before trials. Implementation agents may not alter hidden acceptance tests.
- Run fresh-context implementation, policy change and bug repair tasks using public docs and local signatures/diagnostics only; retain authentic transcripts and outputs.
- Report pass rate, repairs, total cost, latency, human intervention and false acceptance. Compare equivalent strict TypeScript+tests and verification-oriented baselines with comparable budgets.
- Publish failures and uncertainty. A bounded pilot does not prove general model superiority or discharge the broader S7 study by assertion.

## Traceability

PRD G8/S7; the small consumer pilot stays active while broader S7 remains post-mvp.
